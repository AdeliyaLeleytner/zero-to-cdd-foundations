# Требования к pull request

Исправление должно помогать читателю понять материал или воспроизвести результат. Опишите проблему и то, что меняется после правки.

## Текст и изображения

- Следуйте [шаблону главы](../../course-material/ru/WRITING_TEMPLATE.md).
- Проверьте объяснение терминов, обозначения, единицы и переходы между разделами.
- Для нового фактического утверждения приведите подходящий источник.
- Храните изображения в `images/` соответствующей части; приложите исходник или скрипт генерации.
- Сохраняйте вопросы и задачи в конце главы; ответы размещайте отдельно.

## Код и проверка

Из корня репозитория выполните:

```sh
python3 scripts/check_chapters.py --all
python3 -m unittest discover -s tests
```

При изменении расчёта приведите команду и ожидаемый результат. При изменении структуры каталогов проверьте ссылки в README и главах. Для изменений необязательного рендера документации дополнительно выполните `pnpm build`.

## Описание изменения

Укажите, какую задачу решает правка, что проверено и какие ограничения остаются. Не выдавайте выполнение учебной модели за воспроизведение научного эксперимента. Перестановку, добавление и объединение глав сначала отразите в программе README.
