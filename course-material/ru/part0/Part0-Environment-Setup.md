# Перед началом: подготовка окружения

Теоретические главы читаются прямо в репозитории. Для двух готовых практикумов достаточно Python 3.10 или новее; внешние Python-библиотеки, GPU и загрузка данных не требуются.

## 1. Проверка Python

В терминале из корня репозитория:

```sh
python3 --version
python3 course-material/ru/part2/code/identity.py
python3 course-material/ru/part2/code/binding.py
```

Первая программа показывает, что перенумерация атомов сохраняет граф, а изменение связности может изменить молекулу. Вторая воспроизводит расчёты связывания. Если команда `python3` не найдена, установите поддерживаемую версию Python с [официального сайта](https://www.python.org/downloads/).

## 2. Проверка материалов

```sh
python3 scripts/check_chapters.py --all
python3 -m unittest discover -s tests
```

Проверяются локальные ссылки, структура глав и научно значимые свойства учебного кода. Ожидаемый результат — отсутствие ошибок. Эти проверки дополняют самостоятельный разбор, но не измеряют понимание читателя.

## 3. Воспроизведение иллюстраций

Готовые SVG уже находятся рядом с главами в `course-material/ru/part1/images/`. При необходимости их можно заново получить с помощью [uv](https://docs.astral.sh/uv/):

```sh
uv run --no-project scripts/render_figures.py
```

Версии библиотек закреплены внутри скрипта. Структуры генерируются из явных SMILES; графики показывают аналитические модели с учебными параметрами.
