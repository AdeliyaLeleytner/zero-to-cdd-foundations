# Шаблон главы

Опорная версия zero-to-sglang: `2577007cc326f17651c41f6a886906deaa7e3088`; структура повторно проверена 2026-10-03.

Этот репозиторий следует организации [zero-to-sglang](https://github.com/datawhalechina/zero-to-sglang): README с программой, главы в `course-material/<язык>/partN`, изображения рядом с главами, вопросы и источники в конце. Русская версия хранится в `ru/`; несуществующие переводы не обозначаются как готовые.

## Начало

После единственного заголовка H1 идут один-два связных абзаца: предметный вопрос, мотивация и связь с предыдущей темой. Затем — результаты обучения. Введение не заменяется списком терминов.

## Порядок объяснения

Вопрос → понятный образ или схема → механизм → формула с обозначениями → разобранный пример → новая задача. Сохраняйте связную прозу. Введите смысл термина до его активного использования; английское название приводите при знакомстве.

## Структура

```markdown
# Глава N. Название

Предметный вопрос и связь с предыдущей главой.

## 1. Чему вы научитесь

Короткий перечень проверяемых результатов обучения.

## 2. Основное объяснение

Связный текст.

### 2.1 Первый шаг

Механизм, схема, определения, пример.

## 3. Итоги и задачи

### 3.1 Краткий итог

Что читатель теперь понимает.

### 3.2 Задачи

1. Вопрос на объяснение.
2. Задача на применение.
3. ★ Исследовательское расширение.

## Источники и дальнейшее чтение

- Ссылка и короткое пояснение её роли.
```

H2 нумеруются последовательно. H3 используют номер родительского раздела. Последний раздел источников не нумеруется. Структура раскрывается по задаче главы; число разделов не фиксировано.

## Файлы и схемы

Имя главы: `ChapterN_English-Title.md`. Практический разбор кода может иметь суффикс `_code.md`. Изображения находятся в `partN/images/` и включаются относительной ссылкой, с alt-текстом и подписью:

```html
<div align="center">
  <img src="./images/example.svg" alt="Содержательное описание" width="800">
  <p><em>Рисунок 1. Что показывает схема и как её читать.</em></p>
</div>
```

Глава должна полностью читаться в GitHub Markdown. Vue-компоненты и необходимость открывать отдельное приложение для понимания материала не допускаются. Вспомогательная сборка в `docs/.vitepress/` использует те же исходные файлы.

## Числа и источники

Формулы сопровождаются смыслом величин, единицами, допущениями и примером. Учебные числа явно отделяются от измерений. Ссылки на знаковые работы объясняют, какую идею они добавляют; библиографическая проверка не называется полным прочтением или воспроизведением.

## Конец и проверка

Вопросы и задачи стоят в конце главы, затем идут источники. Ответы — в отдельном материале сообщества. Изменение программы отражается в README до изменения нумерации файлов.

```sh
python3 scripts/check_chapters.py --all
```

Проверка ссылок дополняется чтением и выполнением примеров. Лицензии, авторство, институциональные связи и результаты проверки не копируются из репозитория-образца.
