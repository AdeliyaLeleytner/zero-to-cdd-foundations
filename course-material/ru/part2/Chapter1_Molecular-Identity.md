# Глава 1. Молекулярная идентичность: практикум

В [главе о молекулах](../part1/Chapter2_Reading-Molecules.md) мы увидели два требования к представлению: сохранять важные химические различия и не создавать искусственных различий из-за порядка записи. Теперь проверим это в маленькой реализации.

## 1. Чему вы научитесь

- Сравнивать графы с учётом меток атомов.
- Объяснять, почему перенумерация не должна менять результат.
- Видеть ограничения выбранного представления.

## 2. От молекулы к учебному графу

Представим только тяжёлые атомы. Водороды, заряды, порядок связей и стереохимия пока опущены. Поэтому программа проверяет эквивалентность таких графов, а не полную химическую идентичность.

Этанол представлен цепочкой C–C–O, диметиловый эфир — C–O–C. Если стереть метки элементов, останутся одинаковые пути из трёх вершин. Если только перенумеровать этанол, метки и связи можно взаимно сопоставить без потери информации.

## 3. Читаем и запускаем код

Откройте [identity.py](code/identity.py). Функция `equivalent` перебирает взаимные соответствия вершин, проверяет метки, затем сравнивает рёбра. Для маленьких учебных графов этот подход позволяет увидеть весь алгоритм.

```sh
python3 course-material/ru/part2/code/identity.py
```

Результаты для этанола с обратной нумерацией, этанола с эфиром и графов без меток должны быть соответственно `True`, `False`, `True`. Объясните каждый ответ через информацию, которая сохранилась в представлении.

## 4. Итоги и задачи

### 4.1 Краткий итог

Идентичность описывается относительно выбранных признаков. Нумерация вершин произвольна, а химические метки — содержательны.

### 4.2 Задачи

1. Добавьте два графа из четырёх одинаковых атомов: цепь и звезду с тремя рёбрами. Почему одинаковые состав и число связей не делают их эквивалентными?
2. Измените порядок вершин и рёбер этанола. Какой результат должен сохраниться?
3. Какие различия между молекулами этот код заведомо не обнаружит?
4. **★** Как учёт порядка связи изменит представление ребра и проверку соответствия? Почему полный перебор неудобен для больших графов?
